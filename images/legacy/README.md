# Previous logo artwork

Kept for reference after the August 2026 redesign. Nothing in the repository or
the documentation points at these files.

- `cardioception_icon.png` — the circle-and-ECG icon used in the README and as
  the Sphinx sidebar logo. It carried a green-to-red gradient dot inherited from
  the [respyra](https://github.com/embodied-computation-group/respyra) logo,
  which meant nothing here, and it drew three misaligned ECG traces rather than
  anything the task actually produces.
- `favicon.png` — a scaled-down version of the same icon.
- `logo.png`, `logo.svg`, `logo_small.png`, `logo_small.svg` — the older hexagonal
  badge with an anatomical heart and sound waves. Already unreferenced before the
  redesign.

The current logo is a head in profile with a heart in the place of the brain and
arcs rippling out from it: interoception as perception turned inward, rather than
a picture of the recording equipment.
